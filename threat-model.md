# Threat model
Assets: files, fingerprints, metadata, session tokens, custody history, exports. Controls: password hashing, expiring revocable sessions, ORM queries, generated storage names, upload caps, access checks, formula-safe CSV, and hash-chain validation. Residual risks: no email reset/verification, TOTP MFA, digital signatures, distributed rate limits, encryption-at-rest key management, independent checkpoints, or full production audit. A database administrator controlling all copies may undermine a local ledger. Use fictional data only until independent security review.
